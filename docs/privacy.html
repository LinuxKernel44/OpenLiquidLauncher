OpenLiquidLauncher — Privacy Policy

Last updated: October 12, 2026

OpenLiquidLauncher is an open-source Android home-screen launcher. This policy explains what data it does — and does not — handle.

Summary

OpenLiquidLauncher collects no data, sends no data anywhere, and has no internet access (the app declares no INTERNET permission). Everything it stores stays on your device, in the app's own private storage, and is removed when you uninstall it.

What the app stores locally

  • Your home screen layout (apps, folders, widgets, dock, pages) — saved as a local JSON file in the app's private storage.
  • Your chosen wallpaper image, if you pick one from your gallery via the system Photo Picker — kept locally to render the glass effect.
  • Your settings (glass appearance, grid size, gestures, etc.).

None of this ever leaves your device. It is never transmitted, uploaded, sold, or shared with the developer or any third party, because the app has no network code at all.

Permissions, and why

  • Notification access (optional, off by default): used only to show unread-count badges on app icons. The app does not read notification content.
  • Accessibility service (optional, off by default): used only to trigger the "lock screen" and "open notification shade" system actions for gesture shortcuts (e.g. swipe down, double tap). It does not read screen content, your inputs, or any other app's data.
  • Set wallpaper: only used if you choose to also apply your picked image as the system wallpaper.
  • Delete packages: only used when you explicitly uninstall an app from the launcher's UI.
  • Import from another launcher (optional, manual, Settings → Import): reads another launcher's layout (app positions, folder names) on your own device, with your explicit action and consent each time, to copy it into OpenLiquidLauncher. This data stays local and is used only to build your new layout.

Third-party code

The glass rendering is powered by the open-source Kyant0/AndroidLiquidGlass library (Apache-2.0), vendored in the app. It does not add any network or data-collection behavior.

Children's privacy

The app does not knowingly collect any data from anyone, including children, because it does not collect data from anyone at all.

Changes to this policy

If this policy ever changes, the updated version will be published at this same address and in the project's GitHub repository.
